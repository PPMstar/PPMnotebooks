# Wave-Driven Mixing Enhanced by Rotation in Red Giant Branch Stars

This directory contains notebooks required to reproduce figures of "Wave-Driven Mixing Enhanced by Rotation in Red Giant Branch Stars" (Blouin et al. 2025).

| Content                                          | Notebook                                |
|--------------------------------------------------|-----------------------------------------|
| Extract FVmax vs t time series as in Fig. 3      | `FVmax-analysis.ipynb`                  |
| Velocity field visualisation as in Suppl. Fig. 1 | `moms-quivers.ipynb`                    |
| Convective penetration as in Suppl. Fig. 2       | `penetration-rays.ipynb`                |

Simulation data is available at https://doi.org/10.6084/m9.figshare.30273592.
